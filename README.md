# AI Resume Builder 🤖📄

An AI-powered resume builder that helps job seekers and freelancers create professional resumes in minutes. Enter your details, let AI write a strong professional summary and experience bullet points, then preview and download your resume as a PDF.

**Live Demo:** Coming soon (will be added after deployment)

---

## 📌 The Problem

Many people know their experience well but struggle to describe it in a way that impresses recruiters. Writing a strong summary and achievement-focused bullet points takes time, and most resume templates look outdated.

## ✅ The Solution

AI Resume Builder solves this with:
- A simple form for personal details, skills, experience and education
- AI-generated professional summary and bullet points (Google Gemini)
- A clean, modern A4 resume preview that updates as you type
- One-click Print / Save as PDF

---

## ✨ Features

- 🤖 **AI Writing Assistant:** Generate a professional summary and experience bullets from your job title and skills
- 🧾 **Live Resume Preview:** See the resume update in real time
- 🎨 **Modern Dark UI:** Glass-style design with responsive layout
- 🖨️ **Print / Save as PDF:** Export a clean, ATS-friendly resume
- 💾 **Auto-Save:** Your data is stored in the browser (LocalStorage)
- 🌐 **English First:** Designed for international job markets

---

## 🛠️ Tech Stack

- **HTML5** and **CSS3** (Tailwind CSS via CDN, custom styles)
- **Vanilla JavaScript** (no framework)
- **Google Gemini API** (free tier) for AI text generation
- **Lucide Icons** for the icon set
- **LocalStorage** for data persistence
- **Vercel** for hosting

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `index.html` in a modern browser.
3. Paste your free Google Gemini API key in the settings field when prompted.
4. Fill in your details and click **Generate with AI**.

> Note: Your API key is stored only in your browser and is never sent anywhere except Google's API.
